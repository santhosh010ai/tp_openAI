# Travel Planner

This project is a travel itinerary generator that creates personalized travel plans based on user preferences. The planner takes into account the user's interests, budget, and duration of the trip to generate an itinerary with destinations, activities, and weather forecasts.

## Features

- **Itinerary Generation**: Based on the user's preferences, the system generates a travel itinerary.
- **Personalized Recommendations**: The planner tailors the recommendations to interests such as culture, food, adventure, etc.
- **Weather Forecast**: Includes weather forecasts for the selected destinations.
- **Multiple Destinations**: Supports multiple destinations in the itinerary.

- OpenAI API Key
